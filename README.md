## Xrd Keyboard Mod
When injected this mod prevents newly connected controllers from using the first controller slot. This reserves the first controller slot for the keyboard and prevents controllers and keyboard inputs overlapping.

If injected when a controller is already in use, whichever controller is currently in the first slot will need to be unattached and then reattached to cede that slot to the keyboard.

## Running the mod
- Grab the latest build from releases and unzip it.
- Open Guilty Gear Xrd.
- Run GGXrdKeyboardModInjector.exe
